# Node.js Core Assignment

## Objective

Build a basic HTTP server using Node.js core modules
without Express.js.

## Concepts Learned

- HTTP server using the http module
- Node.js event loop and asynchronous execution
- CommonJS modules using require and module.exports
- File reading and writing using fs
- File streaming using createReadStream
- Event handling using EventEmitter
- npm and package.json scripts

## Routes

- GET / - Home page
- GET /api - JSON API response
- GET /write - Write data to a file
- GET /read - Read saved file data
- GET /stream - Stream the HTML file
- Other paths - Return a 404 response

## Run the Project

npm start

## Development Mode

npm run dev

## Dependencies

No external npm packages required.
